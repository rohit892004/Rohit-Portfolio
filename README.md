# Rohit Kumar — Unity / AR-VR / XR Portfolio

A responsive static portfolio website for Unity development, game development, and immersive AR/VR/XR projects.

## Publish with GitHub Pages

1. Create a new **public** repository on GitHub, for example `rohit-portfolio`.
2. Upload `index.html`, `vercel.json` (optional), and `Rohit_Resume.pdf` (if included) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the Pages deployment to finish. Your site URL will be shown in Settings → Pages, usually:
   `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

## Update your website later

- Edit `index.html` directly on GitHub or locally in VS Code.
- Search for `const projects = [` to edit project titles, descriptions, categories, tags, and video URLs.
- Commit/push changes; GitHub Pages republishes the site automatically.

## Video access

Google Drive videos should be shared as **Anyone with the link → Viewer**. Embedded playback depends on Drive permissions and file format. The portfolio provides an open-in-Drive fallback when an embed cannot load.

## Notes

- This is a static website; no build command or backend is required.
- Keep `index.html` at the repository root for the easiest GitHub Pages setup.
